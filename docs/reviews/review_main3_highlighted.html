Method §3.1 — Accept or route

A pipeline reads a document and returns units. A unit is either a field (key–value) or a table (HTML grid). For each unit, EBV outputs accept, meaning it is processed automatically, or route, meaning it goes to a reviewer. A document is accepted only if all its units are, so one doubtful value sends the whole document for review. An upstream label says whether a document is structured, and EBV does no classification of its own. Tables go to Table-Trust, fields in structured documents go to ROI and all other fields go to Signal.

1. "returns units" → "returns its outputs as units."

2. make the decision explicit → "EBV returns one of two decisions: accept (processed automatically) or route (sent to a reviewer)."

3. missing word: "…only if all its units are" → "…are accepted."

4. verb mismatch: "sends" → "routes" (match "route").

5. reads as separate systems; lead with no-classification → "EBV does no classification of its own; an upstream label marks each document as structured or not, and that label determines how each unit is routed: tables to Table-Trust, fields in structured documents to ROI, and all other fields to Signal."

Method §3.3 — Unstructured fields (Signal)

The Signal verifier combines cheap signals computed from the extracted value, the page text, the other extracted fields and statistics learned from labelled history. None needs a generative model or another OCR pass. Format validity checks that the value has the right form for its field. Value-in-text checks that it appears on the page. Keyword context, source context and label–value distance check that the words around it and its position fit the field. Cross-field copy flags a value repeated from another field, and some domains add a partial-extraction or type-mismatch signal. Two more features describe emptiness. One says whether the value is empty, and the other is the field's historical empty rate, the field prior. For each document type, a random forest and a gradient-boosted classifier are trained offline on these features, and the one with higher accuracy on a held-out part of the labelled training data is used, so test data play no part in the choice. Its probability is the field's trust score. …

To evaluate EBV, each extracted value is labelled correct or incorrect by comparing it with the dataset's gold value. Structured fields are compared by field-aware exact match. Unstructured fields are compared by normalised bidirectional containment, which accepts formatting differences and shortened forms such as "12 Main St" and "12 Main Street". On the unstructured benchmarks we evaluate scalar key–value fields. On the proprietary corpus the gold value is the production system's finalised value, corrected by a person where needed. Analysis §6 — para 2 ordering (good content, poor order)

Numbers correct; paras 1 & 3 fine. Only para 2 ("the empty-field prior carries the most weight"): the result is stated before the method, and the S-1 scope dangles.

On free-form fields, the empty-field prior carries the most weight. Removing the empty-field prior lowers AUROC from 0.957 to 0.654 (Δ0.30), more than removing any content signal. Many extractor errors are empty outputs on fields that are usually filled (944 of 1,334 Signal errors). This comes from a drop-one ablation on a surrogate tabular classifier that reproduces the deployed Signal probabilities. About 95% of its instances are S-1, so the result describes S-1. The content signals are each informative but overlap heavily. Dropping any single one costs ≈0 AUROC, since the others cover for it. We therefore credit the content signals only for what they add on top of this cheap prior. The claim has limits. On FCC and Charities the prior has no usable variance (Table 1), so the 0.90 and 0.71 there come from content.

Suggested order (method → scope → result → interpretation):

  1. "We ran a drop-one ablation on a surrogate tabular classifier that reproduces the deployed Signal probabilities; about 95% of its instances are S-1, so the result describes S-1." (method + scope first)
  2. "Removing the empty-field prior lowers AUROC from 0.957 to 0.654 (Δ0.30), more than any content signal, because many extractor errors are empty outputs on fields that are usually filled (944 of 1,334 Signal errors)."
  3. "The content signals are each informative but overlap heavily: dropping any single one costs ≈0 AUROC, since the others cover for it."
